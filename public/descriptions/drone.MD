This project involved building a custom FPV (First Person View) drone from individual components. I selected and assembled each part manually, gaining hands-on experience in electronics, soldering, firmware configuration, and flight tuning.

![Drone](https://i.postimg.cc/2yBSrWZb/drone.png)

## Key Features

- **Custom-built FPV drone** using separate parts.
- **Hands-on soldering** of ESCs, motors, and flight controller.
- **Firmware flashing and configuration** using Betaflight.
- **Radio and video system setup** for full FPV control.
- **Maiden flight testing and PID tuning** for stable performance.

## Build Process

1. **Component Selection**  
   Researched and sourced high-quality components including:
   - Flight Controller (FC)
   - Electronic Speed Controllers (ESCs)
   - Motors and Propellers
   - Video Transmitter (VTX)
   - FPV Camera
   - 5.8GHz Antenna
   - Receiver and Radio System

2. **Soldering and Assembly**  
   Carefully soldered motor wires to ESCs and connected the FC. Ensured clean wiring layout for efficient repairability and airflow to the video transmitter.

   [![IMG-3621.avif](https://i.postimg.cc/5Nb2ZXt0/IMG-3621.avif)](https://postimg.cc/Sj149NCF)

3. **Firmware Configuration**  
   Flashed and configured the flight controller using **Betaflight**, calibrating the accelerometer and tuning flight settings.

4. **System Testing**  
   Checked motor directions, receiver inputs, and video signal. Tested failsafe and arming procedures.


## Skills Gained

- Electronic soldering and component integration
- Drone assembly and mechanical setup
- Betaflight firmware configuration
- Basic flight tuning and PID control
- Troubleshooting and iterative improvement


## Final Thoughts

This project deepened my understanding of drone technology and embedded systems. Building and flying an FPV drone from scratch has been both a technical and rewarding experience.
